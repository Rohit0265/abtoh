# 🎵 Spotify Clone (Frontend Web App)

A fully functional **Spotify-inspired music player** built using **pure HTML, CSS, and JavaScript**.

Although this is a frontend project, it includes **real music playback features**, making it more than just a static UI clone.

🔗 Live Demo: https://music-player-rsm.vercel.app

---

## 🚀 Features

- ▶️ Play & Pause music  
- ⏭ Next & Previous track  
- 🎚 Seek bar (progress control)  
- 📱 Fully responsive design  
- 🎨 Clean and modern UI inspired by Spotify  

---

## 🧠 What Makes This Project Special?

Unlike basic UI clones, this project focuses on **real interactivity and functionality**:
- Implements actual audio control using JavaScript
- Handles dynamic track switching
- Includes responsive layout for different screen sizes
- Provides a smooth user experience similar to real music apps

---

## 🛠 Tech Stack

- **HTML5**  
- **CSS3**  
- **JavaScript**  

No frameworks, no libraries — built from scratch to understand core web fundamentals.

---

## 📚 Learning Outcomes

Through this project, I learned:
- DOM manipulation in JavaScript  
- Working with the HTML Audio API  
- Building interactive UI without frameworks  
- Responsive design principles  
- Structuring real-world frontend projects
